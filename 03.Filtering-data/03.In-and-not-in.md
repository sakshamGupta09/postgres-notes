# In and Notin

- Used to check if a value exists in a list or not. Returns true or false.
- Could be implemented with `OR`, `AND` as well but this is more readable.

```sql
SELECT
	*
FROM movies
WHERE
	movie_lang IN ('English', 'Chinese', 'Japanese')
ORDER BY
	movie_lang ASC;
```

```sql
SELECT
	*
FROM movies
WHERE
	director_id NOT IN (13, 10)
ORDER BY
	director_id ASC
```
