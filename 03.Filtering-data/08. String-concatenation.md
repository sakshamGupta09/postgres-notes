# String Concatenation

- We can use `||` double pipe operator to concatenate two strings.
- If one value is `NULL` resultant will be `NULL` too.
- No proper way to handle seperators.

```sql
SELECT
	first_name,
	last_name,
	first_name || ' ' || last_name AS "full_name"
FROM actors
```

## CONCAT

- If any value is `NULL`, resultant is not `NULl`. `NULL` values are simply ignored.
- No proper way to handle seperators.

```sql
SELECT
	first_name,
	last_name,
	CONCAT(first_name, ' ', last_name) AS "full_name"
FROM actors
```

## CONCAT_WS

- Combines two strings with a sperator.
- Smart enough to ignore `NULL` values and not add seperator in that case.

```sql
SELECT
	first_name,
	last_name,
	CONCAT_WS(first_name, ' ', last_name) AS "full_name"
FROM actors
```
