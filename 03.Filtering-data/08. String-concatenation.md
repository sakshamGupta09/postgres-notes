# String Concatenation

- We can use `||` double pipe operator to concatenate two strings.
- If one value is `NULL` resultant will be `NULL` too.

```sql
SELECT
	first_name,
	last_name,
	first_name || ' ' || last_name AS "full_name"
FROM actors
```

## CONCAT

- If any value is `NULL`, resultant is not `NULl`. `NULL` values are simply ignored.

```sql
SELECT
	first_name,
	last_name,
	CONCAT(first_name, ' ', last_name) AS "full_name"
FROM actors
```
