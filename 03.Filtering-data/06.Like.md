# Like

- Till now we have used the equality checks. Wheter a column value is equal to this or not.
- Now, we want to check for partial matches or pattern matching. I want to select all the rows where this column matches this pattern. Imagine a user typing in search field on an e commerce application.
- `%` sequence of zero or more characters.
- `_` matches exactly one character.
- `LIKE` is case sensitive. `ILIKE` is not.

```sql
SELECT
	*
FROM actors
WHERE
	first_name LIKE 'A%'
ORDER BY
	first_name ASC
```

```sql
SELECT
	*
FROM actors
WHERE
	first_name LIKE '_____'
ORDER BY
	first_name ASC
```
