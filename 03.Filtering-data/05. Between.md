# Between

- Check if a value is coming in this range or not.
- Can be implemented with `AND` operator.
- Low and High are inclusive.


```sql
SELECT
	*
FROM actors
WHERE
	actor_id BETWEEN 1 AND 4
```

```sql
SELECT
	*
FROM movies
WHERE
	release_date BETWEEN '1998-01-01' AND '2002-12-31'
ORDER BY
	release_date ASC
```
