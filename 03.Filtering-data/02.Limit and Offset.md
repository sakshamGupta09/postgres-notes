# Limit

- To limit number of records that we get from the DBMS server.
- More data means more bandwidth and time to transfer it over the wire and also can be bad for memory.
- `LIMIT` clause is written at the end.
- Useful in top n type of queries when used with `ORDER BY`.

```sql
SELECT
	*
FROM movies
WHERE
	movie_lang = 'English'
ORDER BY
	movie_length DESC
LIMIT 5
```

```sql
SELECT
	*
FROM movies
ORDER BY
	movie_length DESC
LIMIT 5;
```

## Offset

- To implement pagination.
- Let's say as a result of a query, we get 1 million resulting rows.
- Now we will keep sending 20 records at a time and client will ask for next set of 20 records.
- FROM → WHERE → SELECT → ORDER BY → OFFSET → LIMIT

```SQL
SELECT
	*
FROM movies_revenues
ORDER BY 
	revenues_domestic DESC NULLS LAST
OFFSET 5
LIMIT 5
```
