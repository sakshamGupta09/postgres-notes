# List Partition

- We partition by a column which has known number of values like ISO country codes.


```sql
CREATE TABLE orders (
  id BIGSERIAL,
  region TEXT,
  amount INT
) PARTITION BY LIST (region);
```

```sql
CREATE TABLE orders_india PARTITION OF orders
FOR VALUES IN ('India');

CREATE TABLE orders_us PARTITION OF orders
FOR VALUES IN ('US');

CREATE TABLE orders_uk PARTITION OF orders
FOR VALUES IN ('UK');
```

```sql
EXPLAIN ANALYZE
SELECT * FROM orders
WHERE region = 'India';
```

```sql
UPDATE orders
SET amount = amount + 100
WHERE region = 'India';
```
