# Alter partition bounds

- Let's say we have a range partition and we want to change it's bounds.
- Process is DETACH the partition from parent partition and then reattach it with new values.

```sql
BEGIN TRANSACTION;

ALTER TABLE t1 DETACH PARTITION t1_p1;
ALTER TABLE t1 ATTACH PARTITION ti\1_p1 FOR VALUES FROM (0) TO (200


COMMMIT TRANSACTION;
```
