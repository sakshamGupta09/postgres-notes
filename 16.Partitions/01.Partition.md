# Partitions

- Partitioning is splitting a large table into smaller tables (partitions) based on a rule.
- If we are frequently quering a large table based on 2 columns, instead of doing full table scan on parent table, we can instead split up the parent table into partitions based on the frequent coluns.


## Table inheritence

- Children automatically gets all columns from the parent.
- Can add their own extra columns


### Parent table

```sql
CREATE TABLE employees (
    id INT,
    name TEXT
);
```

### Child tables (inherit from parent)

```sql
CREATE TABLE developers (
    programming_language TEXT
) INHERITS (employees);

CREATE TABLE managers (
    team_size INT
) INHERITS (employees);
```
