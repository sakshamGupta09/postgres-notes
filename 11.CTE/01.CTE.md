# CTE

- Usually, we write a query, get back some results and that's it. There is no mechanism to store those results in some temporray table.
- Store the result of this query in a temporary table with this name so that I can use this table in some query later.
- Lifetime of a CTE is till the query in which it is used.

## Syntax

```sql
WITH cte_name AS (
  QUERY
)
SOME OTHER QUERY
```

```sql
WITH movies_of_director_1 AS (
	SELECT
		*
	FROM movies
	WHERE
		director_id = 1
)
SELECT
	*
FROM movies_of_director_1
```

```sql
WITH long_movies AS(
	SELECT
		*
	FROM movies
	WHERE
	movie_length > 120
	ORDER BY
		movie_length ASC
)
SELECT
	*
FROM long_movies
```

```sql
WITH movies_with_type AS (
SELECT
	movie_id,
	movie_name,
	movie_length,
	(CASE
		WHEN movie_length < 100 THEN 'Short'
		WHEN movie_length < 120 THEN 'Mediun'
		ELSE 'Long'
	END) AS "movie_type"
FROM movies)
SELECT
	*
FROM movies_with_type
WHERE
	movie_type = 'Long'
```
