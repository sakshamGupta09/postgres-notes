# Union

- We have multiple SELECT statements that give us some result sets.
- We want to merge those results into a single result set.
- Result sets to be merged must have same number of columns and data types as final result set will also have a type.
- Column names of result set will be as per the first result set in union statement.
- Duplicates are discarded.

```sql
SELECT
	movie_id,
	movie_name
from movies

UNION

SELECT
	director_id,
	age_certificate
from movies

```
