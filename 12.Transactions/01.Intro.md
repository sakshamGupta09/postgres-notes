# Transactions

- Some tasks require multiple SQL operations.
- The ask is that all these operations must succeed. Only then the task will be marked as completed.
- If any one operation fails, entire task fails.
- When the task fails, we need to undo the changes done in the transaction and take our DB to prior transaction state.


## How DB is protected during a transaction

- During a transaction, every operation performed is logged into a log file.
- If anything interrupts the transaction (hardware, software or power issues),the transaction ends and we can restore the system to original state by issuing a ROLLBACK statement.
-  ROLLBACK statement will undo all the changes stored in the log file.
