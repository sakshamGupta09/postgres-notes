# Exists


```sql
WHERE EXISTS (subquery)
```

- Usually with `IN`, `ANY` and `ALL`, We always compare a column with result set values.
- `EXISTS` don't care about the values.
- Returns TRUE if subquery returns ≥ 1 row.
- Doesn’t care about actual values
- Stops early → fast


## Example

Does this customer have any order?

```sql
SELECT name
FROM customers c
WHERE EXISTS (
    SELECT 1
    FROM orders o
    WHERE o.customer_id = c.id
);
```


Suupliers who supply products less than 100 dollars
```sql
SELECT
	*
FROM suppliers s
WHERE EXISTS (
	SELECT 1
		FROM products
		WHERE
			supplier_id = s.supplier_id AND
			unit_price < 100
);
```
