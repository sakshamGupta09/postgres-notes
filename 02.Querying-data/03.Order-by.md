# Order By

- By default, new rows gets inserted at the bottom of the table. When we read data, we get oldest rows first.
- But we can ask for sorted rows based on one or more column values.
- Default order is `ASC`

```sql
SELECT
  *
FROM Table
ORDER BY
  C1 [ASC | DESC],
  C2 [ASC | DESC]
```

## Execution Sequence

- `FROM` -> `WHERE` -> `SELECT` -> `ORDER BY`
- Sorting is always done on the resulting set.

## Order by Aliases

- We can use aliases also for sorting.

```sql
SELECT
	 first_name,
 	last_name,
	 gender,
	 date_of_birth AS "dob"
FROM actors
ORDER BY
	 gender ASC,
	 dob DESC;
```

```sql
SELECT
	first_name,
	last_name,
	LENGTH(first_name) AS "length"
FROM actors
ORDER BY
	length DESC;
```

## Order by column number

- Now instead of sorting by column names, we can instead sort by column order in the resulting set.
- If we change the order of columns, this flow will break. Also, it's not very intuitive and readable at first glance.

```sql
SELECT
	first_name,
	last_name,
	LENGTH(first_name) AS "length"
FROM actors
ORDER BY
	1 ASC,
	3 DESC;
```

## How NULLS are sorted

- By default, If we sort by a column that has `NULL` values in ASC, `NULL` values comes at the last. On sorting in DESC, `NULL` appears first.
- We can modify this behavior by passing `NULLS LAST` OR `NULLS FIRST` to `ORDER BY`.

```sql
SELECT
	first_name,
	last_name
FROM actors
ORDER BY
	first_name ASC NULLS FIRST;
```
