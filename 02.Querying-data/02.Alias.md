# Aliasing columns

- As a techie, we might be following a specific nomenclature for our table columns.
- But for other people that nomenclature might not make too much sense. So, We should be able to customize column names while reading data.
- When we use inbuilt functions like string functions or aggregation functions, our column automatically gets a weird name.
- Internally, column names still remain unchanged, only in the resulting set we get customized column names.


```sql
SELECT
  C1 AS "SOME_OTHER_NAME"
FROM Table
```

```sql
SELECT
	first_name || ' ' || last_name AS "Full Name"
FROM actors;
```

- It's better to use double quotes. Single quotes doesn't work and gives an error.


## As keyword is optional

- But still for readability and intent it's better to use it.

```sql
SELECT
  C1 "SOME_OTHER_NAME"
FROM Table
```
