# Any

- The subquery returned multiple records.
- Now, for every row in the outer query, we want to check if any value in the result set is satisfying a condition. Not just equality like in case of `IN` operator.
- Operators can be `<`, `>`, `=`, `<>` etc.
- `IN` is equivalent to `= ANY`


## Syntax

```sql
SELECT
  C1,
  C2
FROM table
WHERE
  C1 operator ANY (SUBQUERY)
```

```sql
SELECT
	*
FROM customers
WHERE
	customer_id = ANY
	(
		SELECT
			o.customer_id
		FROM orders o
		INNER JOIN order_details od
		ON o.order_id = od.order_id
		WHERE
			od.quantity > 20

	)
```
