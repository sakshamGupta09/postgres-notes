# Subqueries

- One query produces a value or result set that is needed by another query as input to generate the output.

```sql
Outer Query
  (Inner query)
```

## Inner query returning one value

- Find all movies where movie length is greater than average movie length.
- Here we cannot use Aggregate function inside WHERE clause.

```sql
SELECT
	movie_name,
	movie_length
FROM movies
WHERE
	movie_length > (
SELECT
	AVG(movie_length)
FROM movies
)
ORDER BY
	movie_length ASC

```

- Find all actors younger than James Dean.
- We need to find the age of James Dean.

```sql
SELECT
	first_name,
	last_name,
	date_of_birth
FROM actors
WHERE date_of_birth >
(
	SELECT
		date_of_birth
	FROM actors 
	WHERE
		first_name = 'Douglas' AND 
		last_name = 'Silva'
);

```


## Inner query returning multiple records

- If inner query is returning multiple records, we need to compare each row of outer query and check if that row is there in inner result set using IN operator.


- Find all movies whose domestic revenue is greater than 200.

```sql
SELECT
	movie_id,
	movie_name
FROM movies 
WHERE
	movie_id IN
(
SELECT
	movie_id
FROM movies_revenues
WHERE
	revenues_domestic > 200
)
```

## Subqueries with joins

```sql
SELECT
	director_id,
	first_name,
	last_name
FROM directors
WHERE
	director_id IN
(
SELECT
	m.director_id
FROM movies m
JOIN movies_revenues mr
ON m.movie_id = mr.movie_id
WHERE
	mr.revenues_domestic + mr.revenues_international > 
	(
		SELECT
			AVG(revenues_domestic + revenues_international)
		FROM movies_revenues
	)
);
```

## Order union entries without order by

 - Typically we would do something like this to sort entries in a union result.
 
```sql
SELECT
	first_name,
	'actors' AS "table"
FROM actors

UNION

SELECT
	first_name,
	'directors' AS "table"
FROM directors
ORDER BY
	first_name ASC;
```

- We can use subqueries on FROM clause as well not just WHERE.
