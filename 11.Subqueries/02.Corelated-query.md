## Correlated Queries

- A normal subquery runs once.
- A correlated subquery runs for every row of the outer query.
- It is used when inner query needs some values from the outer query.


## Example

- Find employees who earn more than the average salary of their department

```sql
SELECT name, salary, dept_id
FROM employees e1
WHERE salary > (
    SELECT AVG(salary)
    FROM employees e2
    WHERE e2.dept_id = e1.dept_id
);
```

## Rewrite correlated query using Joins

```sql
SELECT e1.name, e1.salary, e1.dept_id
FROM employees e1
JOIN (
    SELECT dept_id, AVG(salary) AS avg_sal
    FROM employees
    GROUP BY dept_id
) avg_table
ON e1.dept_id = avg_table.dept_id
WHERE e1.salary > avg_table.avg_sal;
```
