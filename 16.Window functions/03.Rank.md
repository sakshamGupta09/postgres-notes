# Rank

- `ROW_NUMBER` was giving different values to rows with same salary. This is not fair. Students who get same marks should all be first.
- Two rows with same value will get the same `rank` and `dense rank`.
- Imagine we have to pick Top 3 records and they all have same value. It's unfair to use `ROW_NUMBER` because they all are having equal value still one row is prioritized over other.

## Rank vs DENSE_RANK

- Rank creates holes or gaps when there are rows with duplicates.
- Dense rank creates compact ranking.
- RANK() → Think of a race: if two people finish 2nd, the next person is 4th.
- DENSE_RANK() → Think of grouping: if two people are in rank 2, the next distinct value is rank 3.
