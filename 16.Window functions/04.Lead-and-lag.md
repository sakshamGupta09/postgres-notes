# Lead and Lag

- To compare a row in an ordered partition with it's previous or next row.
- Like compare the highest salary with the second highest one. I want to compare the person who came first wit the person who came second.
- If the next row or previous does not exists, it returns NULL.

## Syntax

```SQL
SELECT
  *,
  LEAD(column_name, Row number from current row, Default is 1, Replace NULL with current row column value),
  LAG(column_name, Row number from current row, Default is 1, Replace NULL with current row column value)
FROM table
```

> Lead with ASC and LAG with DESC will produce the same results.
