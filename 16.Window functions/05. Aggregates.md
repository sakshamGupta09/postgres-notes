# Window Aggregate Functions

- When we use group by with aggregation, we get back one row with typically two columns.
- With aggregation, we get back all the rows in a partition plus some additional columns.

## SUM

- Let's consider we need to find total salaries paid, department wise.
- For every row in a partition, we will get a new column called total salary whoch will use sum aggregation.
- We can compare individual contribution with total value.
- If we do it traditional way, First we will create a table which will hold aggregation of department and total salary, then join it with employees table.

```SQL
SELECT
  employee_id,
  employee_name,
  department,
  SUM(salary) OVER (PARTITION BY department) AS "total_salary"
FROM employees
```
- Order by no longer is necessary.
