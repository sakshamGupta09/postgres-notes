# ROW_NUMBER()

- For every partition in which we have rows in some ordered manner, assign serial number to all my rows.
- Useful when we want to extract Top K items within a group.


## Example

- Suppose we have two tables `products` and `orders`.
- I want to find top selling products category wise.

## Solution

- First we need to aggregate quantity and total amount for each product in `orders` table as a product can be ordered several times.
