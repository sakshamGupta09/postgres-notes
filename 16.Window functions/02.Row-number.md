# ROW_NUMBER()

- For every partition, we have arranged rows in a manner, now please assign serial number to all my rows.
- Useful when we want to extract Top K items within a group.


## Example

- Finding the highest salary per department.


```SQL
WITH RankedEmployees AS (
    SELECT
        emp_id,
        name,
        department,
        salary,
        ROW_NUMBER() OVER (
            PARTITION BY department
            ORDER BY salary DESC
        ) AS rn
    FROM Employees
)
SELECT
    emp_id,
    name,
    department,
    salary
FROM RankedEmployees
WHERE rn <= 2
ORDER BY department, salary DESC;
```
