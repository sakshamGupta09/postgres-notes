# Why window functions

- Let's say we want to compute maximum salary of employee per department.

```SQL
SELECT
  department,
  MAX(salary)
FROM employees
GROUP BY department;
```
- Simple enough, But this query returns department and maximum salary not the details of employee who is getting maximum salary.
- When we do grouping, we get the column we group by and an aggregation result, rest all columns are lost.
- Imagine now, We want to have top 2 employees per department with highest salaries. Grouping only return us one row, How do we solve this then?


## Syntax

- While grouping, we are asked to output a single row.
- Here while creating partitions, we don't have to restrict our partition output to a single row.

```SQL
WINDOW_FUNCTION OVER (How to divide table into partitions)
```

```SQL
ROW_NUMBER() OVER (PARTITION BY DEPARTMENT ORDER BY salary DESC)
```
- Create department wise partitions. Add employees to that partition in an ordered way.
- Assign a row number to all records in a partition.
- Output all rows in a partition and combine them across partitions.
