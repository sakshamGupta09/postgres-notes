# Expression index

- Normally indexes stores a column value.
- But let's say while querying data, we are using some functions like LOWER, UPPER or EXTRACT.
- In that case our indexes will not work because they are storing raw values and we end up performing a full table scan.
- Expression indexes help us in storing result of an expression rather than a column value. When we use the same function in the query, we can leverage index scan.
