# Index types

- Indexes are different “data structures” optimized for different kinds of queries.

## B-Tree 

- Best for
-  Equality: =
- Range queries: <, >, BETWEEN
- Sorting: ORDER BY
- This is used in ~90% of real-world cases.


🔹 Use case

- Find users with age = 25
- Find users with age > 30
- Sort users by age

## Hash Index

- Best for
- Only equality: = or exact match
- No range queries, No sorting, Rarely better than B-Tree, In practice: almost never needed


## GIN

- Perfect when a column contains multiple values.
- Best for
- Arrays
- JSONB
- Full-text search
