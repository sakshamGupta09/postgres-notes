# Indexes

- We have a table with 1 million rows.
- We ran some query with a WHERE clause and got back 100 results.
- 1 million rows were scanned to return back 100 rows. This is a problem.

## Data strcuture

- An Index is a data structure that holds column values in an ordered way along with a pointer to original table row.
- When we run a read operation, it first goes to the index and gets relevant rows. Then it goes to parent table to get all columns of those matching rows.


## Write operations

- Whenever we perform any write operation like INSERT, DELETE or UPDATE we need to perform it on the table as well as on the indexes, so index impacts write operations.


## Unique Index

- Some columns in our table should only hold unique values like a users email, phone number or identity proofs.
- We create a unique index that does not allows a column or group of columns to have a duplicate value.
