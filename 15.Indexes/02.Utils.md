# Utils


## List all indices

- In a production grade environment, we might have thousands of tables.
- Using PgAdmin tool to browse throgh them and then see the indexes can be difficult to navigate.
- Instead we have a table where all the index information is stored and we can query it like:

```sql
SELECT
	tablename,
	indexname,
	indexdef
FROM pg_indexes
WHERE
	tablename = 'orders';
```


## Size of indexes in a table

- Indexes are data structures that are physically stored on the disk.
- To check how muuch space indexes are taking for a table, we use this command:

```sql
SELECT
	pg_size_pretty(pg_indexes_size('orders'))
```
