# Utils


## List all indices

- In a production grade environment, we might have thousands of tables.
- Using PgAdmin tool to browse throgh them and then see the indexes can be difficult to navigate.
- Instead we have a table where all the index information is stored and we can query it like:

```sql
SELECT
	tablename,
	indexname,
	indexdef
FROM pg_indexes
WHERE
	tablename = 'orders';
```


## Size of indexes in a table

- Indexes are data structures that are physically stored on the disk.
- To check how muuch space indexes are taking for a table, we use this command:

```sql
SELECT
	pg_size_pretty(pg_indexes_size('tableName'))
```


## Statistics to know if a index is used or not

- Check how are indexes are used in production. Are they even used or not.
- We have a table named `pg_stat_all_indexes`

```sql
SELECT
	schemaname,
	relname,
	indexrelname,
	idx_scan,
	idx_tup_read,
	idx_tup_fetch
FROM pg_stat_all_indexes;
```

### idx_scan

- Number of times this index was used in queries.
- High value indicates frequent usage.
- 0 value means it can be removed.


### idx_tup_read

- Rows scanned via index

### idx_tup_fetch

- Rows actually returned
