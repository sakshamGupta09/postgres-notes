# Explain

- Lets say we added optimizations like indexes and partitions but how do we know if they are working or not.
- We need to learn how postgress is executing our query. We can ask potgres for the execution plan.
- It does not execute the query just gives us the winning plan to execute a query. So, everything here is estimated not actual.


```sql
EXPLAIN your_statement
```

## Output format

- By default the output format of EXPLAIN is TEXT. But we can have it in JSON as well.

```sql
EXPLAIN (FORMAT JSON) statement
```

## Explain Analyze

- EXPLAIN shows what PostgreSQL plans to do.
- EXPLAIN ANALYZE Shows what actually happened when the query ran.

```sql
EXPLAIN ANALYZE statement
```
