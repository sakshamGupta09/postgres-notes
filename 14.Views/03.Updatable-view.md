# Updatable view

- Till now we learned how we can use a view to read, filter, sort data. We can also add data to tables using a view.
- An updatable view is a view on which you can run INSERT, UPDATE or DELETE commands but it always performs them on the underlying table.
- A view is automatically updatable only if it is simple enough. Based on single table, No aggregation, No GROUP BY, No DISTINCT, No JOIN.
- The user to which we provided a view access and not the whole table should be able to run UPDATE, DELETE and INSERT commands also on the subset view.


```sql
CREATE OR REPLACE VIEW vu_directors AS
SELECT
	first_name,
	last_name
FROM directors
```

```sql
INSERT INTO vu_directors
(first_name, last_name)
VALUES
('DIR ', '1'),
('DIR', '2')
```

## With Check

- Lets say in our view query we have a WHERE clause on some columns.
- Ideally, since we are adding or updating data through a view, data that respects the WHERE clause conditions only should be allowed to be inserted or updated.

```sql
CREATE OR REPLACE VIEW v_us_cities AS
SELECT
	*
FROM tb_locations
WHERE
	country_code = 'US'
```

- Now if we run insert query like below, it will accept.

```sql
INSERT INTO v_us_cities (country_code, city) VALUES 
('UK', 'City 3')
```
