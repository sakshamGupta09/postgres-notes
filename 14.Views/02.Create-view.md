# Create view

```sql
CREATE OR REPLACE VIEW name AS QUERY
```

```sql
CREATE OR REPLACE VIEW v_movie_directors AS
SELECT
	m.movie_id,
	m.movie_name,
	m.movie_length,
	m.movie_lang,

	d.first_name,
	d.last_name
FROM movies m
JOIN directors d 
ON m.director_id = d.director_id;
```


## Access data from a view

- instead of writing long complex queries, we just write a view name.

```sql
SELECT
	*
FROM v_movie_directors
```


## Filtering views

- Since view is a virtual table, we can do filtering on it like usual tables.
