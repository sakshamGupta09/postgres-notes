# Why views

- Views are saved queries that behave like virtual table.
- They don't store data just the query and show results of the query when we access them.
- When we access a view, the query runs and returns the result.


## 1. Simplify Complex Queries

- If you frequently write complex joins or aggregations, views save you from repeating them.
- You define the complex query once, and reuse it easily.

```sql
SELECT u.name, o.total
FROM users u
JOIN orders o ON u.id = o.user_id
WHERE o.status = 'completed';
```

## 2. Data Security

- Let's say we have a table with sensitive data.
- Instead of giving access to entire table, we can create a view that exposes some columns and hides teh sensitive ones.

```sql
CREATE VIEW public_user_data AS
SELECT name, email FROM users;
```
