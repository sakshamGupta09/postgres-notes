# CTE

- Store the result of this query in a temporary table with this name so that I can use this table in some query.
- Lifetime of a CTE is till the query in which it is used.

## Syntax

```sql
WITH cte_name AS (
  QUERY
)
SOME OTHER QUERY
```

```sql
WITH movies_of_director_1 AS (
	SELECT
		*
	FROM movies
	WHERE
		director_id = 1
)
SELECT
	*
FROM movies_of_director_1
```
