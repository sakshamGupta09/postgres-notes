# Type conversion

- Convert a column value from it's original type to some other type.

```sql
SELECT
	*
FROM movies
WHERE
	movie_id = '1';
```

- Here, `movie_id` is an integer type but we are comparing it with a string. So, postgres automatically converts string to an integer and then performs the comparison.

```sql
SELECT
	*
FROM movies
WHERE
	movie_id = INTEGER '1';
```
- Explicit conversion.


## Cast

CAST (COLUMN AS TARGET_DATA_TYPE)

```sql
SELECT
	CAST('10' AS INTEGER);
```
