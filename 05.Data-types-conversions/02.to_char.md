# TO_CHAR(column, format)

- convert numbers or dates into formatted strings.
- Always returns `TEXT` type.


## Dates

| Pattern | Meaning                |
| ------- | ---------------------- |
| YYYY    | Year (2026)            |
| MM      | Month (01–12)          |
| Mon     | Short month (Jan, Feb) |
| Month   | Full month             |
| DD      | Day                    |
| Day     | Weekday name           |
| HH24    | Hour (24-hour)         |
| MI      | Minutes                |
| SS      | Seconds                |

```sql
SELECT to_char(NOW(), 'YYYY-MM-DD');
SELECT to_char(NOW(), 'DD Mon YYYY');
SELECT to_char(NOW(), 'Day, DD Month YYYY HH24:MI:SS');
```


## Numbers

| Pattern | Meaning             |
| ------- | ------------------- |
| 9       | Optional digit      |
| 0       | Mandatory digit     |
| .       | Decimal point       |
| ,       | Thousands separator |
| $       | Currency symbol     |


``` sql
SELECT to_char(1234567, '9,999,999');
SELECT to_char(1234.5, '9999.00');
SELECT to_char(1234.5, '$9999.99');
```
