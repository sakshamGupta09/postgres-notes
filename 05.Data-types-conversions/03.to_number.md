# to_number(text, format)

- Converts string representation of a number to numeric values.


## Format

| Pattern | Meaning             |
| ------- | ------------------- |
| `9`     | digit               |
| `0`     | required digit      |
| `.`     | decimal point       |
| `,`     | thousands separator |
| `$`     | currency symbol     |


```sql
SELECT to_number('1234', '9999');

SELECT to_number('1,234,567', '9,999,999');

SELECT to_number('1234.56', '9999.99');

SELECT to_number('$1,234.50', '$9,999.99');
```
