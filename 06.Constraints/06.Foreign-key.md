# Foreign key

- To establish relationship between tables.
- It is a column in a table that references primary key of another table.

## Problem without foreign keys

- Lets say we have two related tables but not using foreign key.
- Ideally, in the parent table column, we should be allowed to enter only those values that exist in foreign table's primary key column. But without foreign key we are free to enter any value even if that doesn't exists in foreign table's primary key column.
