# Foreign key

- To establish relationship between tables.
- It is a column in a table that references primary key of another table.

## Problem without foreign keys

- Lets say we have two related tables but not using foreign key.
- Ideally, in the parent table column, we should be allowed to enter only those values that exist in foreign table's primary key column. But without foreign key we are free to enter any value even if that doesn't exists in foreign table's primary key column. Inserts or updates happen.
- Let's say we delete a record from the foreign table. Ideally it should not be allowed because parent table still references that data. But it works perfectly fine.
