## Group By

- We have one big table and we want to split it into multiple sub tables based on some criteria.
- Criteria is that the column should have same values.
- On every group, we perform some aggregation function and return one single row per group.
- In the final result set, there will be no duplicates.

## Execution order

- FROM → get table
- WHERE → filter rows
- GROUP BY → create groups
- HAVING → filter groups
- SELECT → pick columns
- ORDER BY → sort result

```sql
SELECT
	movie_lang,
	COUNT(movie_id) AS "movies_count"
FROM movies
GROUP BY
	movie_lang
ORDER BY
	movies_count DESC
```

```sql
SELECT
	movie_length
FROM movies
GROUP BY
	movie_length;
```
