# Having

- `HAVING` operates on the groups created and decides if this group shoul be considered or not.
- Since it's about filtering a group, we always use AGGREGATE function as conditions in HAVING clause.
- HAVING AGGREGATE_FUNCTION (value) > value

```sql
SELECT
	movie_lang,
	SUM(movie_length) AS "duration"
FROM movies
GROUP BY
	movie_lang
HAVING
	SUM(movie_length) > 200
ORDER BY
	movie_lang ASC;
```
