# Using

- If two tables to be joined have same related column name, instead of ON syntax we can use USING.

```sql
SELECT
	m.*,
	
	d.*
FROM movies m
JOIN directors d
USING (director_id)
WHERE
	m.movie_lang = 'English';
```

```sql
SELECT
	m.*,

	mr.*
FROM movies m
JOIN movies_revenues mr
USING (movie_id)
```
