# Transaction Setup

## Begin

- Creates or opens a new transaction block.
- Whtever operations we perform after this are all counted as one transaction.

```sql
BEGIN;
```

## Operations

```sql
UPDATE accounts
SET 
	balance = balance -50
WHERE
	account_id = 1
```
- Since this operation is inside an transaction, this will not be visible to other users unless COMMIT happens.


## Commit

```sql
COMMIT;
```
