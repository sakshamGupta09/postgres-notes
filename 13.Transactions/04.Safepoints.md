# Safepoints

- With `COMMIT` and `ROLLBACK`, we can either save or rollback an entire transaction block.
- But we want to ROLLBACK to a particular step in a transaction block not revert all teh changes.
- At every command we add a SAVEPOINT and then we can revert to a particular SAVEPOINT.

```sql
SAVEPOINT name
```

```sql
ROLLBACK TO savepoint_name
```
