# Transactions

- A transaction is a group of SQL operations executed as a single unit — either all succeed or all fail.
- If any opertaion fails, system undoes everything and goes to a state before transaction started.
- For example, If we want to transfer funds from Account A to Account B. One operation will be to deduct amount from Account A and then add that amount to Account B. Now the operation is successful when both the operations complete. If any one of them fails, entire operation fails and we need to undo changes .


## How DB is protected during a transaction

- During a transaction, every operation performed is logged into a log file.
- If anything interrupts the transaction (hardware, software or power issues), we can restore the system to original state by issuing a ROLLBACK statement.
