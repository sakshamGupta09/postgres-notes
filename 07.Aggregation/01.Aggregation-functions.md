# Aggregation

- Perform an operation using all the values in this column and return the output.
- Any aggregation function can be performed on unique values of a column by using `DISTINCT`.
- `NULLS` are always ignored while performing operation on a column.


## Count

- `COUNT(*)` returns the total number of rows in a table.
- `COUNT(column)` return the count of NOT NULL values.

```sql
SELECT
	COUNT(*)
FROM movies;
```

## Count with distinct

```sql
SELECT
	COUNT (DISTINCT movie_lang)
FROM movies;
```

## Count with where clause

```sql
SELECT
	COUNT(*)
FROM movies
WHERE
	movie_lang = 'English';
```


## SUM

- Sum all the NOT NULL values present in this column and return the output.
- Works with numbers only.

```sql
SELECT
	SUM(revenues_domestic)
FROM movies_revenues;
```
