# Aggregation

- Perform an operation using all the values in this column and return the output.
- Any aggregation function can be performed on unique values of a column by using `DISTINCT`.
- `NULLS` are always ignored while performing operation on a column.


## Count

- `COUNT(*)` returns the total number of rows in a table.
- `COUNT(column)` return the count of NOT NULL values.

```sql
SELECT
	COUNT(*)
FROM movies;
```

## Count with distinct

```sql
SELECT
	COUNT (DISTINCT movie_lang)
FROM movies;
```

## Count with where clause

```sql
SELECT
	COUNT(*)
FROM movies
WHERE
	movie_lang = 'English';
```


## SUM

- Sum all the NOT NULL values present in this column and return the output.
- Works with numbers only.

```sql
SELECT
	SUM(revenues_domestic)
FROM movies_revenues;
```


## Min and Max

```sql
SELECT
	MAX(movie_length)
FROM movies
```

```sql
SELECT
	MIN(release_date)
FROM movies 
WHERE
	movie_lang = 'Chinese'
```


## Greatest and Least

- `MAX` and `MIN` gives the output by comparing all the values in a column.
- `Greatest` and `LEAST` works on a single row and return the greatest value among columns in a single row.
- Types must be comparable. strings with numbers won't work.

```sql
SELECT
	revenues_domestic,
	revenues_international,
	GREATEST(revenues_domestic, revenues_international),
	LEAST(revenues_domestic, revenues_international)
FROM movies_revenues;
```
