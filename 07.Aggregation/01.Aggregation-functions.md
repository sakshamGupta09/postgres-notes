# Aggregation

- Derive a single value from all the values in this column.


## Count

- `COUNT(*)` returns the total number of rows in a table.
- `COUNT(column)` return the count of NOT NULL values.

```sql
SELECT
	COUNT(*)
FROM movies;
```

## Count with distinct

```sql
SELECT
	COUNT (DISTINCT movie_lang)
FROM movies;
```

## Count with where clause

```sql
SELECT
	COUNT(*)
FROM movies
WHERE
	movie_lang = 'English';
```
