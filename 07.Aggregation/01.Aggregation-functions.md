# Aggregation

- Perform an operation on all the values of this column and return the output.


## Count

- `COUNT(*)` returns the total number of rows in a table.
- `COUNT(column)` return the count of NOT NULL values.

```sql
SELECT
	COUNT(*)
FROM movies;
```

## Count with distinct

```sql
SELECT
	COUNT (DISTINCT movie_lang)
FROM movies;
```

## Count with where clause

```sql
SELECT
	COUNT(*)
FROM movies
WHERE
	movie_lang = 'English';
```


## SUM

```sql
SELECT
	SUM(revenues_domestic)
FROM movies_revenues;
```
