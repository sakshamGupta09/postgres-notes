# Date functions

## CURRENT_*

- We have a computer on which postgres is installed. Current functions gives us the current value of date and time in that computer.
- `CURRENT_DATE` Returns the current date in `YYYY-MM-DD` format.
- `CURRENT_TIME` Returns the current time in `HH::MM::SS` format.
- `CURRENT_TIMESTAMP` Returns the current date and time in  `YYYY-M-DD HH::MM::SS` format.
- Sometimes, we want to store current date and time information. Instead of passing value from application layer to DB, we can use these functions as the default values.


## EXTRACT

- We have a timestamp and we want to extract individual parts from it.
- `EXTRACT(something) FROM timestamp_column`. Something can be `YEAR`, `MONTH`, `DAY`, `WEEK`.
- `DATE` function takes a timestamp and returns the date value in `YYYY-MM-DD` format.
- `TIME` function takes a timestamp and returns the time value in `HH::MM::SS` format.


## DATE_ADD, DATE_SUB

- We use `INTERVAL` to add or subtract something from a timestamp.

```SQL
date_or_timestamp + INTERVAL 'value unit'
``` 
- Unit can be `DAY`, `MONTH`, `YEAR`.


## Difference

- If both columns are of type DATE subtracting them will give number of days.
- Subtracting two timestamps returns an INTERVAL
- Use `EXTRACT(EPOCH FROM interval)` to get the difference in seconds, then convert as needed.
- Use `AGE` to get the difference in years months and days.

```SQL
SELECT end_date - start_date AS days_difference
FROM bookings;

5
```

```SQL
SELECT TIMESTAMP '2026-07-30 15:30:00'
     - TIMESTAMP '2026-07-30 12:00:00';
03:30:00
```

```SQL
SELECT EXTRACT(EPOCH FROM (end_time - start_time)) AS seconds;
```

```SQL
SELECT AGE(DATE '2026-07-30', DATE '2024-04-15');

2 years 3 mons 15 days
```
