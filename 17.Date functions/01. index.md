# Date functions

## CURRENT_*

- We have a computer on which postgres is installed. Current functions gives us the current value of date and time in that computer.
- `CURRENT_DATE` Returns the current date in `YYYY-MM-DD` format.
- `CURRENT_TIME` Returns the current time in `HH::MM::SS` format.
- `CURRENT_TIMESTAMP` Returns the current date and time in  `YYYY-M-DD HH::MM::SS` format.
- Sometimes, we want to store current date and time information. Instead of passing value from application layer to DB, we can use these functions as the default values.
