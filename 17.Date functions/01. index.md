# Date functions

## CURRENT_*

- We have a computer on which postgres is installed.
- Current functions gives us the current value of date and time in that computer.
- `CURRENT_DATE` Returns the current date of the OS on which postgres is running in 'YYYY-MM-DD' format.
- `CURRENT_TIME` Returns the current time of the OS on which postgres is running in 'HH::MM::SS' format.
