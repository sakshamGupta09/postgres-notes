# Numbers

- Numbers are mostly categorized as integers and decimals.
- Integer types are `SMALLINT`, `INTEGER`, `BIGINT`. Each type has a range of accepted values. If we provide a out of range value, we will get an error. It includes positives as well as negatives.
- `SERIAL` is a postive auto increment integer starting from 1. `SMALLSERIAL`, `SERIAL`, `BIGSERIAL`.
- For decimals we have `NUMERIC`, `REAL` and `DOUBLE PRECESION` types.
-  `NUMERIC` is used for storing Money / financial data when the value must be exact. Bcause numerics are stored exactly as we input. If we input 0.1, DB will store 0.1 only. Whereas with floating types, system might internally store something like `0.100000000000000005`. If we provide less decimal places, it will add zeroes, if more it will round off.
-  `DOUBLE PRECISION` for scientific calculations and measurements. 8 bytes and has 15 places precision. If we specify less decimals, no padding.
-  `REAL` just to save storage as it take 4 bytes only as compared to 8 bytes for DP and takes 6 places of precision.
