# Text  data

- I want to store text values in my table. What types are there and when to choose which.
- We generally have three types to store text values.


## 1. Character

- Fixed length data type. If we know that our value will hold exactly n characters always, we can use this type.
- Example, Aadhar, PAN , Phone, OTP.
- If we supply less than n charcters, it will add spaces to make it n.
- If we supply more characters than n, we get an error.


## Character Varying

- Sometimes, we do not know in advance the exact number of characters. Example name of a user.
- Also, we do not want extra spaces.
- If we supply, less than n characters, no spaces are added. If we supply more, we get an error.
- It's more like an upper limit of a text. n means maximum number of characters.
