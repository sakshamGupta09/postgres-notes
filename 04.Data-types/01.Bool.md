# Data types

- What kind of values can be stored in a table column.


## Boolean

- Sometimes, we just need to store yes or no in our table. Example `isMarried`, `isActive`, `inStock`.
- Valid values are `true`, `false` and `NULL`.
- We can pass 'true', 't', 'yes', 'y', '1' and 'false', 'f', 'no', 'n', '0' but internally it will always be stored as `true` or `false`.
