# Date

- Default format is `YYYY-MM-DD`.
- `CURRENT_DATE` gives us the current date in the system postgres in running on.

## Time

- Time with timezone and Time without timezone.
- Used to store only the time in `HH:MM:SS` format.
- `CURRENT_TIME` returns time with timezone `HH:MM:SS.123456-tz`

## Interval

- Interval is used to add or subtract day, hours, minutes , years to a date or time objects.
- `INTERVAL n type` n is a number positive or negative and type can be DAY, MONTH, HOURS, MINUTES, SECONDS


## Timestamp

- To store data with time.
- Internally, our data is always stored as UTC. So, if we supply a timezone, it uses that offset and stores a UTC value. Similarly, If we do not provide a timezone, server timezone is selected and converted to UTC.
- When reading timestamp value, the value is first converted from UTC to our server timezone.
- `CURRENT_TIMESTAMP`
- SELECT TIMEZONE(timezone, TIMESTAMP) to convert a particular timestamp to a given timezone.
