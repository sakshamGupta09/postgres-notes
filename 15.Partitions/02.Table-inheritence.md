# Table inheritence

- Children automatically gets all columns from the parent.
- Can add their own extra columns.
- Constranints and indexes are not copied.


## Parent table

```sql
CREATE TABLE employees (
    id INT,
    name TEXT
);
```

## Child tables (inherit from parent)

```sql
CREATE TABLE developers (
    programming_language TEXT
) INHERITS (employees);

CREATE TABLE managers (
    team_size INT
) INHERITS (employees);
```

## Query parent table

```sql
SELECT * FROM employees;
```
- This returns data from ALL child tables also.

## Only parent (exclude children)

```sql
SELECT * FROM ONLY employees;
```


## Update/ Delete parent table

- We can update and delete child records through parent table.


## Drop parent table

- Drop command will give an error as there are child tables depending on it.
- Either we first drop the child tables and then drop parent tables.
- Or we can use CASCADE option with drop command.
