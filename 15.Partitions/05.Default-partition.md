# Default Partition

- If we try to insert data which can't fit in any of the partitions, we get an error.
- `INSERT` fails because Postgres does not know where to insert that record.
- To solve this, we create a default partition. If we cannot put our data in any of the partitions, we put it into default one.
- Over time, if we get more and more data in default partition, we can extract it out as a seperate partition.
