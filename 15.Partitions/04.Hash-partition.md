# Hash Partition

- If we are unable to find a partition key or want a more uniform distribution.
- Imagine you have 1 million rows and you want to split them into 4 buckets: You do something like: `user_id % 4`
- Column is used in equality queries only. Greater than or less than queries wont be effective.
- Postgress will randomly put data in buckets.


```sql
CREATE TABLE users (
  id INT,
  name TEXT
) PARTITION BY HASH (id);
```


```sql
CREATE TABLE users_p0 PARTITION OF users
FOR VALUES WITH (MODULUS 4, REMAINDER 0);

CREATE TABLE users_p1 PARTITION OF users
FOR VALUES WITH (MODULUS 4, REMAINDER 1);

CREATE TABLE users_p2 PARTITION OF users
FOR VALUES WITH (MODULUS 4, REMAINDER 2);

CREATE TABLE users_p3 PARTITION OF users
FOR VALUES WITH (MODULUS 4, REMAINDER 3);
```
