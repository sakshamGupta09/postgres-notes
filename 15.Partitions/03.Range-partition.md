# Range Partition

- Mostly used with dates. We can create daily, weekly, monthly, yearly partitions.
- We manually need to create partitions.
- Whenever we perform an INSERT/UPDATE/DELETE operation, data is automatically populated in respective partitions.
- These operations are always performed on main table but they change data is respective partitions.

```sql
CREATE TABLE orders (
  id BIGSERIAL,
  order_date DATE NOT NULL,
  amount INT
) PARTITION BY RANGE (order_date);
```

```sql
CREATE TABLE orders_2023 PARTITION OF orders
FOR VALUES FROM ('2023-01-01') TO ('2024-01-01');

CREATE TABLE orders_2024 PARTITION OF orders
FOR VALUES FROM ('2024-01-01') TO ('2025-01-01');
```
