# Cross Join

- Each row in left table is joined with every row in the right table.
- Result is also called the cartesion product.
- If left table has m rows and right table has n rows, resulting table will have m *n rows.


```sql
SELECT
  T1.C1,
  T1.C2,

  T2.C1,
  T2.C2
FROM T1 CROSS JOIN T2
```

``` sql
SELECT
  T1.C1,
  T1.C2,

  T2.C1,
  T2.C2
FROM T1, T2
```
