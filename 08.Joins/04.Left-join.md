
# Left join

- All the rows from the left table will be part of resulting set.
- Rows for which there is no matching record in foreign table, will be assigned NULL values.

```sql
SELECT
	m.movie_name,

	d.first_name,
	d.last_name
FROM movies m
LEFT JOIN directors d
ON m.director_id = d.director_id;
```

```sql
SELECT
	d.director_id,
	COUNT(*) AS "movies_count"
FROM directors d
LEFT JOIN movies m
ON d.director_id = m.director_id
GROUP BY
	d.director_id
ORDER BY
	movies_count DESC;
```
