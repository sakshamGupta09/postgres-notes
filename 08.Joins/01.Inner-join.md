# Inner Join

- Return only the matching rows.
- If one colum matches with multiple rows in foreign table all the rows are included in the resulting set.


```sql
SELECT
  table1.column1,
  table2.column1
FROM table1
JOIN table 2
ON table1.key_column = table2.key_column
```

```sql
SELECT
	movies.movie_id,
	movies.movie_name,
	movies.movie_lang,

	directors.first_name,
	directors.last_name
FROM movies
JOIN directors
ON movies.director_id = directors.director_id;
```

## Table Alias

```sql
SELECT
	m.movie_id,
	m.movie_name,
	m.movie_lang,

	d.first_name,
	d.last_name
FROM movies m
JOIN directors d
ON m.director_id = d.director_id;
```


## Filtering

```sql
SELECT
	m.movie_id,
	m.movie_name,
	m.movie_lang,

	d.first_name,
	d.last_name
FROM movies m
JOIN directors d
ON m.director_id = d.director_id
WHERE
	m.movie_lang = 'English';

```

## Selecting all columns

```sql
SELECT
	m.*,
	d.*

FROM movies m
JOIN directors d
ON m.director_id = d.director_id
WHERE
	m.movie_lang = 'English';

```
