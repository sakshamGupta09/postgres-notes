# Execution Stages

- How DB executes a SQL query.


## 1. Parsing (Syntax Check)

- PostgreSQL first reads your SQL statement and checks if it’s valid.
- Checks syntaxes and the table names, column names.


## 2. Planning (Query Planner / Optimizer)

- Lays out all possible options to execute the query provided like Full table scan, index scan, partitions etc.
- Figures out the best possible approach to execute a given query.


## 3. Execution

- Executes the query plan generated by palnning phase.


## 4. Returning Results

- Final results are sent back to the client.
