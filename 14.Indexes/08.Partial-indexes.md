# Partial Index

- By default, when we create an index on a column, for every row of the table, we get an entry in the index data structure.
- We do not need to store every row in the index.
- Let's say we are only querying for users who are older than 50. In that case storing rest of the userr ages is of little to no use. Our index space reduces and searching it will be faster.
- On the downside, if a query comes that does not meet index condition, full scan will be performed.

```sql
CREATE INDEX index_name ON table_name
WHERE condition
```

## Example

- Lets say we have inactive users in our platform which is less than 10 percent of total users.
- In this case we should create a partial index only on inactive users.
- Because active users will return 90% of the data.
- We managed to speed up our query as well as reduce disk space.
