# Sorting

- If we have very large data say several million rows in our table, sorting it is gonna be very very slow.
- Since `indexes` already store ordered values, we can use indexes to speed up our sort operations as well. Sorting is no longer required at all. If we use `EXPLAIN` on our query, there will be no SORT phase at all.
- Not only sorting and reading but operations like `MIN`, `MAX` as we already have ordered data. Here the main table doesn't need to be referenced at all.
